## Forge 40d: the CRM library app
Built 2026-11-28 ([CRM.md](CRM.md), [Records.md](Records.md) › *Built in forge 40d*, [Live.md](Live.md) › *Changed in forge 40d*). The `crm` library app (`features/crm/app`, seeded by Forge like Calendar's): seven entity types, Sales rep and Sales manager with owner rules on the types, five commands, three queries and seven tools; the node *Move record* (`records.move`), so a command graph moves a ranked record with its other writes in one commit; and a fix in the live core's projector, which re-read the rest of a batch for each of its events (a 500-row `record.upsert` took minutes to project, so a second import read records not yet projected). Later parts: write a deal's stage only through `deal.moveStage` (`crm.moveDeal`), owners only through `record.reassign`, contacts in bulk through `crm.importContacts`; CRM users are tenant members as well as Sales reps or managers.
