## Forge 40a to 40c: charts, the relation picker and CSV import
Built 2026-11-27 ([ServerUI.md](ServerUI.md) › *Built in forge 40a and 40b*, [Records.md](Records.md) and [Services.md](Services.md) › *Built in forge 40c*). Primitives `mui.chart` (Recharts, lazy-loaded; the dashboard palette moved to `frontend/common/src/components/charts/palette.ts`), `mui.metric` and `mui.relationPicker` (now `record.fieldEditor`'s relation input); the command `record.upsert` (batches of 500, matched on a field, one command each); the nodes *Parse CSV* and *Prepare rows*; the `records` section's `importMaxRows`; `features/text/delimited` and `parseservice`, wired from `features/wiring/parse.go` through the new `wiring.Feature.Services` hook. Later parts: import and form submissions write with `record.upsert`, never with one `record.create` per row; a refusal's `args.rows.<n>` names rows to drop and resend; files from strangers that need no child process are read in a service (`parseservice`), never in the node; a new parser is a new `parseservice` operation.
