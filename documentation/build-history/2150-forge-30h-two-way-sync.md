Built 2026-11-28 ([Tasks.md](Tasks.md) › *Built in forge 30h*). Two-way sync of a Tasks project with a `tasks.tracker@1` board, as the app's blueprints: an import job paging `card.list` with lists mapped to statuses, a push on our changes (not the app's own) with the card's version, a pull on `card.changed` dropping echoes by version, and conflicts settled by the later change, with the loser logged in `taskSyncLog`. Later parts: the Trello, Asana, Linear and Jira types (30i, 30j, 30o) only implement the contract, and the sync works with them unchanged. A graph that must tell its own writes from people's reads `_updatedBy` (0 for an app) and keeps triggers at `ownChanges: false`.
