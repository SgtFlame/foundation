**Extension points** - `features/extensions` (see `documentation/Contributors.md`): the owning feature declares `var X = extensions.NewPoint[T](id, description)`, where a contribution `T` embeds `extensions.Descriptor{ID, Order, Source}`; contributors call `X.Register(reg, c)` from a `Contribute(reg *extensions.Registry)` function that `serve.go` calls explicitly (no `init()` side effects), and readers call `X.All(reg)`. `serve.go` declares each point with `registry.Declare(...)`.
