A feature's `wiring.Feature.Seed(ctx, wiring.Started{Store, Apps, Bus, Tenants})` runs once the live core and services are up, before requests are served (`wiring.SeedAll` in `serve`; background work is `Feature.Start(ctx, env)`, `wiring.StartAll`, forge 35a-2), for idempotent start work such as seeding a library app in every tenant (forge 30c: `tasks.SeedApp`); it runs in every process at every start.
