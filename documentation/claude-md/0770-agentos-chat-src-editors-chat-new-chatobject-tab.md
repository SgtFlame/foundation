- **AgentOS** - Chat (`src/editors/chat/`, `new ChatObject()`, tab `chat:main`): a continuous scroll of conversations that opens on the latest one and continues it (✕ on its divider or `/new` starts another; scrolling up loads earlier ones), with the level toggle (hover: model and estimated input cost), the ⚙ context settings, `/` commands and Stop. Replies render with `MarkdownText` with citation chips; below a reply are its Chronicle chips (the pinned entries; a chip opens the entry), its Sources row and Context inspector (when segments were injected; the inspector's *Why* is a pinned segment's `reason`), the memory update's line and, on hover, 👍/👎/🚫 and the footer (level, model, tokens, cost, latency). A citation opens the cited file with its lines selected (`openMarkdownAt` in `editors/markdown/openMarkdown.ts`, asking through `editors/markdown/reveal.ts`, which Live Preview reads once the document has loaded). Dashboard (`src/editors/dashboard/`, `new DashboardObject()`, tab `dashboard:main`): the `dashboard.widget` grid, starting with *Usage & cost*. Cognition (`src/editors/cognition/`): opens the built-in Personal graph (read-only; *Duplicate* to edit) in the Cognition Editor.
