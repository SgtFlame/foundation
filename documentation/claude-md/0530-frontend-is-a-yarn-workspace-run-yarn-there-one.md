`frontend/` is a Yarn workspace (run `yarn` there; one `yarn.lock`, one hoisted `node_modules`). `common` (`@foundation/common`) holds all of the frontend code: pages, components, editors, tabs, services, settings and the workbench. It is consumed as TypeScript source, never built on its own: its `exports` map `@foundation/common/<path>` to `src/<path>` and `@foundation/common/vite` to `vite.ts`, the `foundation()` Vite plugin (the shared Monaco/Yjs resolution and the dev proxy of `/api/v1/<route>` to the backend; add a new backend route to its `routes`, and an app's own routes with `foundation(backend, more)`). `cd frontend/common && yarn build` type-checks it, and `yarn test` runs its unit tests (`src/**/*.test.ts` with `node --test`, forge 15e; a tested module uses only type imports from the rest of common). An app is only its entry: `frontend/example` is the reference app, with `index.html`, `public/`, `vite.config.ts` (`plugins: [react(), foundation()]`), `src/main.tsx` (imports `@foundation/common/index.css` and `@foundation/common/register.ts`, then renders `App`) and `src/App.tsx` (the theme and the routes, from common's pages). New code goes in `common`; paths below are relative to `frontend/common`. `cd frontend/example && yarn build && yarn lint` builds and checks the app.
