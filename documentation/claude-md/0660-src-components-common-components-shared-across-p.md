- `src/components/` - common components shared across pages or editors; one-use components live with the page or editor that uses them. `components/chat/` holds the chat surface pieces (`useChatStream`, `ChatTranscript`, `RoundView`, `RoundSources` (the Sources row and the Context inspector), `FeedbackButtons`, `ChatComposer`, `LevelToggle`, `ChatSettingsPopover`, `ToolCallCard`, `useContextSettings`, `levels.ts`), shared with the planned Markdown Chat tab; `components/markdown/MarkdownText.tsx` renders read-only markdown with Live Preview's renderer (`livePreview({ revealSelection: false })`) and, given `citations`, shows each valid `[n]` as a clickable chip (`citations.ts`: Lezer parses `[1]` as a link, so the text is rendered with `⟦n⟧` in its place). `components/folders/` holds the folder-browsing pieces both volume editors use: `useFolderListing` (listing, errors, `run` an operation then reload), `FolderBreadcrumbs`, `NameDialog` and `ToolbarAction` (an icon button whose tooltip shows while disabled and which carries the title as its accessible name). `components/logs/LogRow.tsx` renders one `LogRecord`, for both DevTools' Log tab and the Log Explorer; `components/json/JsonView.tsx` is the collapsible JSON tree.
