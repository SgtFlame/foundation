**Docs pages** (`features/docs`, forge 35a-2, `documentation/Docs.md`): the `docs` library app (`docsapp.Files`, seeded by Forge's starter) keeps a page per document file `pages/<id>.doc.json` in a Volume, the tree in the `docsPage` records (`parent`, `ancestors`, `rank`, `childCount`); change pages only through `docs.page.*` and the `createPage`/`purgePage` tools, never raw `record.*`. A Volume's grants are the floor (*May use Volume*). A feature's background work goes in `wiring.Feature.Start` (`wiring.StartAll`), and `record.move` in a command graph is *Move record*.
