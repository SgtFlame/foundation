**Git connector** (`features/connectors/git`, forge 24, `documentation/GitConnector.md`): `git.repo@1` (refs, trees, files, compare, keyed commits to a branch, the `pushed` event) and `git.review@1` (pull requests); every type passes `git/contracttest.Run`, adds the commit key as an `Axiom-Key` trailer (`git.WithKey`/`HasKey`), and reads change files only through `git.Decode`; test against the Git test server `gittest.repo` (`gittest.control@1`: push, fail, protect, merge, log).
