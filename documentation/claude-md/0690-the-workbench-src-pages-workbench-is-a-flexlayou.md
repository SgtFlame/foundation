The workbench (`src/pages/workbench/`) is a `flexlayout-react` host with a `SideBar`: a vertical tab per `workbench.sideView` contribution (`{ title, icon, width?, collapsible?, component }`, given `{ registry, collapsed }`) and the open view beside them; clicking the open view's tab hides it, and a `collapsible` view's chevron narrows it to its own width with `collapsed` set (remembered per view). The **Editors** view (collapsible) lists every `workbench.command` (`{ title, icon?, section?, run({ registry }) }`) that has a `section`, one per line with its icon and title, grouped by section in the order of their first command; collapsed, it shows only the icons, the title as tooltip. Its model is built on first render, after discovery. Its borders come from `workbench.borderTab` contributions (`borders.ts`: one border per location that has tabs, all collapsed; later contributions join an existing border, and a removed one's tab is deleted); each border tab's component is `borderTab`, rendered by `BorderTabHost` from the contribution.
