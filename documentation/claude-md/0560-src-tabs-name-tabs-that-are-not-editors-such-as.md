- `src/tabs/<name>/` - tabs that are not editors, such as `devtools/` (`DevToolsTab`, a nested flexlayout with the Network, Live (the live connection's frames), Log, Extensions and Usage viewers, contributed to the workbench's right border) and `settings/` (`SettingsTab`: search, scope selector, category tree and a `SectionPanel` per section, rendering `SchemaField`, the generic schema form, or the section's own `Editor`). The Extensions viewer lists every browser point (`extensions.snapshot`) and the server's (`Extensions.listPoints`); the Usage viewer pages through `Usage.records`.
