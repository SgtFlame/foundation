- `src/settings/` - settings for the browser: `points.ts` (the `configuration` point), `contributions.ts` (the Settings border tab, and `loadServerSections()` adding the server's sections), `configStore.ts` (`useConfig(section)`, `useSetting(section, path)`: read settings only through these; one `config.changes` subscription refetches changed sections, and everything after a reconnect) and `schema.ts` (the schema type and value helpers: `getAt`, `setAt`, `patchFrom` for the merge patch a form saves).
