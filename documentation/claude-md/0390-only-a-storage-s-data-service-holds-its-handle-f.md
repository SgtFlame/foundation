Only a storage's data service holds its handle (forge 21d, `documentation/DataServices.md`): `go test ./features/db/guard` fails for a new package importing `gorm.io/gorm` or JetStream outside its allow list. Code that writes another feature's tables takes the owner's interface (`tools.CallStore`, `engine.Traces` (`engine.New(traces.In(gdb), …)`, superseding `engine.New(db, …)` above), `chronicle.Memory`, `usage.Store`, `authz.Source`), never a `*gorm.DB`.
