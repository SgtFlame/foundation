**Infrastructure as Code** (`features/infra`, forge 22a to 22f, `documentation/Infrastructure.md`): configurations (`infra.config.*` ops on `def`, root tenant only) commit versions, `infra.plan` compares one with what exists (`infra.compute@1` per provider account, the Control Plane's records) and `infra.apply` runs the plan's steps as `infra-apply-step` jobs that enqueue the steps they unblock; `infratest` is the in-memory test provider, `infra/nodes` the ensure nodes over the Control Plane's records. Add resource kinds on `infra.resourceKind`.
