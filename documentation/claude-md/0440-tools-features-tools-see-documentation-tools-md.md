`tools` (`features/tools`, see `documentation/Tools.md` › *Built in slice 8*) is function calling. A `tools.Tool` is a struct (`Descriptor` ID = the dotted name, sent to the model with `.` as `_`; `Title`, `Description`, `Input` JSON Schema, `Effect` `none|read|write|external|ui`, `Asks(args)` deciding per call whether it asks in place of its effect (`Tool.AsksFor`; slice 41: `forge.apply` asks only for a batch that publishes, installs or writes records), `Location` `server|client`, `Wait`, `Run(tools.Call) (tools.Result, error)`); a tool reads its arguments with `tools.Decode[T](call)` after the loop's `CheckArgs`, and returns `Result{Content map, Summary markdown, Segments}`, where segments become citations; an error's text goes to the model and the user, so it names nothing private (pass a service's `Common.Message`). `tools.Loop{DB, Chat}.Run(RunArgs)` is the one tool loop: it streams each step, runs calls (consecutive quiet ones in parallel), asks a `Gate` before `write`/`external` calls unless `Allowed`, has the gate run client tools, stores a `ToolCall` record per call (round or run and node, status, approval, result cut to the `tools` section's `maxResultKB`), and after `maxSteps` makes the model answer; a model call whose error code is `providers.BusyCode` (Gemini's 503 or 429, `providers.Error.Busy`) is tried again up to the `tools` section's `retries`, waiting 2, 4, 8… s (`RunArgs.OnRetry`, chat's `retry` event; slice 43), and `Tool.Timeout` replaces `timeoutSeconds` for one tool. Without a gate (the Agent node) writes are denied, unless the run is an agent's (slice 51: `ApprovalAgent`, its roles decide), and there are no client tools. Per-tenant tools come from the `tools.source` point (`tools.Sources`, slice 51: installed apps' manifest tools `<appId>.<name>`, `installs.ContributeTools`); list a round's or run's server tools with `tools.Available(reg, args)`, never `tools.Tools.All` alone. Chat's gate is in `conversationservice` (`impl/tools.go`): a pausing call is registered by round and call ID before its `tool` event goes out, and `Answer` (`POST /conversation/answer`) delivers the approval or the client result; waiting calls live in memory.
