**User-defined entity types** (forge 35c-1, `documentation/Records.md` › *Built in forge 35c-1*): a running app makes types for its users (a Docs database's properties) with `entity.createUserDefined` (`UserDefined`, `Parent` record; owned by the app, part of no app version) and the nodes *Create entity type*, *Add field*, *Update field*, *Remove field*, *Publish entity type* in `server.action` and `ui.handler` graphs. Changing one needs `record.define` on its parent record (a manifest role's `entity:<type>.define`); never list such types as an app's parts.
