**Document files** (forge 35a-1, `documentation/MarkdownEditor.md` › *Built in forge 35a-1*): a Volume file of type `document` is `<name>.doc.json`, holding `{format: 1, doc: <ProseMirror doc>}` (`features/text/prosemirror`: `Parse`, `Envelope`, `PlainText`, `Markdown`, `Derive` with each top-level block's lines). Everything that reads a Volume file's text reads a document through `volumeservice.TextOf` (its derived Markdown): the index chunks it, retrieval cites its lines and `kb.read` reads them; `kb.createNote` and `kb.edit` stay markdown only. A document room seeds from the file and stores the writer's saves through `volumeservice.DocumentFile` (a file kept byte for byte, a bare doc wrapped, at most `MaxDocumentBytes`; refusals reach the room as `saved` with `errorCode`).
