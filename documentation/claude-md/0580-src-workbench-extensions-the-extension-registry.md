- `src/workbench/extensions/` - the extension registry (`documentation/Contributors.md`). A feature that owns a point declares it in its `points.ts` with `defineExtensionPoint<T>(id, description)` (`src/workbench/points.ts`: `workbench.borderTab`, `workbench.editor`, `workbench.sideView` and `workbench.command`; `src/settings/points.ts`: `configuration`; `src/editors/chat/points.ts`: `chat.contextSettings` and `chat.command`), and a feature contributes in its `contributions.ts` with `extensions.contribute(point, { id, source, order?, when?, ... })`, referencing heavy components with `lazy(() => import(...))`. `src/register.ts` imports every `points.ts` and `contributions.ts` (`import.meta.glob`, eager); an app's `main.tsx` imports it before the first render. Components read a point with `useContributions(point, ctx?)`; a duplicate id replaces the earlier contribution, which keeps hot reload working.
