- Components call these clients; they never `fetch` or use axios on the backend directly. `Chronicle.ts` is the Chronicle client. The one client using `fetch` is `Logs.tail`, because axios cannot stream Server-Sent Events in the browser; it parses with `http/sse.ts` and sets `X-Trace-Id` itself. `Chat.stream` and `Conversation.send` (with `onFollowed`) are calls on the live connection, `Config.events` follows the `config.changes` query and collaboration rooms are its channels; live traffic is logged and shown in DevTools' Live tab, not captured in the Network tab. `Logs.ingest` opts out of capture too, and so do `Secrets.put` and `Config.set` with a patch carrying a secret (`{ secret: true }`): no secret value is ever captured. `Secrets.ts` is the secrets client and `Bootstrap.ts` reads the bootstrap state.
