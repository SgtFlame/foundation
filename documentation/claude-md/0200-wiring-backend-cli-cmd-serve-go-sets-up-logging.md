**Wiring** - `backend/cli/cmd/serve.go` sets up logging (`--log-format text|json`, `--log-level` for stderr, `--vlogs-url` for storage), listens at once behind a `secrets.Gate` that serves only the bootstrap routes (503 `server_starting`, or `server_sealed`, for every other API route) and, with `--vault-addr`, waits to be unsealed (see *Secrets* below), opens and migrates the application and tenant databases, starts embedded NATS JetStream for the live core (`natsd.Start`, `<data-dir>/nats`, no listener; `--nats-url` or `$FOUNDATION_NATS_URL` uses an external server, a cluster with `--nats-creds`, `--nats-ca` and `--nats-replicas`, every stream config passing through `natsd.Stream`/`KV`/`Object` (forge 20a-1, `documentation/Live.md` › *Built in forge 20a-1*); drained after the HTTP server shuts down), creates each service with its `impl.CreateService(...)` (imported as `<s>impl`), then each handler, and calls `Register(api, service)`; once it is done, `gate.Open(router)` serves the router. The router is `gin.New()` with `rest.Middleware(rest.WithAuthenticate(...))` (trace, principal and one log record per request, in place of gin's logger) and `gin.Recovery()`; its groups are `public` (`/api/v1`, only the identity routes), `api` (`public` with `rest.RequireUser()`, where a new handler goes) and `volumes` (`api` with `kbhandlers.InTenant()`, for kb, collab and index). Services that react to each other are joined by in-process buses (`features/events.Bus[T]`, synchronous: subscribers must not block), passed in with `With<Bus>` options, e.g. `volumeservice.FileEvents`.
