An editor contribution with `restorable: true` (app editor kinds always) has its tabs, objects and place in the layout saved in the tab's **workspace** (forge 16b, `documentation/Workspaces.md` › *Built in forge 16b*: `workspace.update {layout}`, debounced, by `workspace/layoutSaver.ts`) and reopened after a reload, a switch or in another browser; other tabs close on a switch, and one whose subject reports `dirty` asks first. Set it only when the object is plain data. The workbench's model is replaced on a switch (`Model.fromJson(json, previous)`, `EditorRegistry.setModel`): never keep a `Model` from the registry, and report unsaved work through `useWorkbenchSubject`'s `dirty`. Adding an editor: create `src/editors/<name>/` with the object, the editor (taking `EditorProps<YourObject>`) and a `contributions.ts` calling `extensions.contribute(editors, { id: '<kind>', source, name, component: lazy(() => import('./<Name>Editor.tsx')) })` and, to list it in the Editors view, `extensions.contribute(commands, { id: 'open-<kind>', source, order, title, icon, section, run: ({ registry }) => registry.edit(new YourObject(...)) })`. `EditorRegistry` also has `rename(tabId, name)` and `close(tabId)`.
