- `src/logging/` - structured logging modelled on Go's `samber/oops`. Use the `log` builder (`log.In('kb').Tags('volume').With('volumeId', id).info('opened %s', name)`), never `console.*`; `Errorf`/`Wrap` build an `OopsError` carrying that context, and `log.fromError(err).error(...)` logs one. Records go to an in-memory ring buffer shown in DevTools' Log tab, are mirrored to the console in dev builds, and go to every sink added with `addLogSink`: `forwarder.ts` (started by `RequireSession`) forwards those from the `logging` section's `browserLevel` (warn) up to the server in batches. A record logged with `fromError(err)` takes the trace of an error that has one (`ServiceError`), so it sits next to the server's records of that request.
