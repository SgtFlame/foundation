- Requests go through the shared axios instance `http` from `src/services/http/client.ts` (e.g. `http.post<Resp>('/kb/volumes/open', request)`), whose baseURL is `API_BASE` (`VITE_API_BASE`, default `/api/v1`). `Retrieval.ts` is the retrieval client, `Cognition.ts` the Cognition client, `Entities.ts` the entity types' (published versions), `Records.ts` the records' (reads, `find` for sorted pages, import, `newRecordId()`), `Prefabs.ts` the prefabs' (published versions, `preview`, and the definition's types for `prefab.describe`), and `Apps.ts` declares the manifest's types for `app.describe` and `app.list` and is `appservice`'s client (`Apps.export|check|import`, resolving 409 and 422 with their problems and import plan). In dev, the `foundation()` Vite plugin (`frontend/common/vite.ts`) proxies `/api/v1/<f>` to the backend on `localhost:8080`; a new feature adds its route to `routes` there, while a new service in an existing feature is already covered.
